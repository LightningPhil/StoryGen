Below is a JSON schema full of detail for generating records for a database. The database is to be of illustrators, artists and photographers with all the obvious data explained in the schema filled in. Most of the data is to allow finding and sorting of which image style would be interesting to use for a particular AI image generation. The stylePrompt is the key and most important part to get right. There is description for it in teh schema. But beyond that, the prompt must be good enough to generate images that are very beleavably similar to the illustrator's, artist's or photographer's style.

The user will, once a style has been chosen which is beyond this chat, type a prompt. We will call that the userPrompt. It will be formed into a complete prompt for the image generating AI as follows:
"Generate an image with the following content/characters:
userPrompt

Use the following style guide for generating the image:
stylePrompt"
